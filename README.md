# AI Policy Analysis in New Zealand Tertiary Education — Figure Generation Code

This repository contains the Python code used to generate the figures
presented in the paper:

> **Generative AI Policy in New Zealand Tertiary Education: A Library-Focused Analysis**
> Ibrahim M. H. Rahman, Eric Boamah, and Simon Jigwan Park
> The Open Polytechnic of New Zealand

The scripts reproduce the data visualisations in the Results section.
Each script is self-contained and can be run independently.

---

## Repository Contents

| File | Figure | Description |
|------|--------|-------------|
| `code_heatmap.py` | Figure 1 | Heatmap of AI policy scores for all 14 institutions across six dimensions |
| `data_code_average_governance_score.py` | Figure 2 | Horizontal bar chart ranking institutions by average governance score |
| `risk_category.py` | Figure 3 | Pie chart of institutions by AI policy risk category |
| `policy_stance.py` | Figure 4 | Bar chart of institutions by policy stance (Supportive, Conditional, Cautious/Restrictive) |
| `disclosure_required.py` | Figure 5 | Pie chart showing the proportion of institutions requiring AI disclosure |
| `radar_chart_comparison_poly.py` | Figure 6 | Radar chart comparing polytechnics across six dimensions |
| `radar_chart_comparison_univ.py` | Figure 7 | Radar chart comparing universities across six dimensions |
| `grouped_bar_score_inst.py` | Figure 8 | Grouped bar chart of dimension scores for all institutions |
